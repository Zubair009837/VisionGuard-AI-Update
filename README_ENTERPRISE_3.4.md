# VisionGuard AI 3.4 Enterprise

## Included
- Single / multi / all-NVR bulk settings from one screen.
- Unique NVR IP values are preserved per recorder; network changes are prepared per NVR.
- NVR user inventory for all configured NVRs with single/multi-account enable, disable and role changes.
- Camera bulk and single configuration APIs.
- IP conflict monitoring across the full configured NVR camera inventory with email alert and recovery.
- Recording gap monitor with 300-second (5-minute) threshold and double verification.
- Camera-to-NVR movement history and alert/email when an identified camera changes NVR.
- Floor Map setup with NVR filtering, camera placement and browser persistence.
- Live Analytics dashboard using real backend telemetry: NVR health, camera counts, alerts, recording loss, storage, camera movements and angle status.
- Dark professional styling overrides for Bootstrap cards/tables/forms so pages do not render white.
- Advanced ISAPI raw XML remains available for expert use.

## Important
IP addresses are unique per NVR. The bulk settings workflow sends a separately prepared payload to each selected NVR instead of copying one NVR's IP to every recorder.
